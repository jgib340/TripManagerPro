Trip Manager Pro Mobile Application

Overview
Trip Manager Pro is an Android mobile application designed to help users organize vacations and related excursions in single location. The application allows users to create and manage vacation details, associate excursions with specific vacations, set alerts for important dates, and share vacations.

Features
- Create, edit, and delete vacations.
- Store vacation details including title, hotel, start date, and end date.
- Associate excursion with specific vacations.
- Create, edit, and delete excursions.\
- Configure alerts for vacation start dates, vacation end dates, and excursion dates.
- Share vacation details using Android's built-in sharing functionality.

Application Structure
The application consists of the following primary screens:
Home Screen - Entry point of the application allowing navigation to the vacation list.
Vacation List Screen - Displays all saved vacations and allows users to create new vacations.
Vacation Detail Screen - Allows users to view and edit vacation information and manage associated excursions.
Excursion List Screen - Displays excursions associated with a selected vacation.
Excursion Detail Screen - Allows users to create or modify excursion details and set alerts.

Technology Stack:
- Language: Java
- IDE: Android Studio
- Database: Room Persistence Library (SQLite)
- Build System: Gradle
- Platform: Android

Installation:
1. Download the provided app-release.apk file.
2. Install the APK on an Android device or emulator.
3. Launch the Trip Manager application from the device's app list.

Minimum Requirements:
- Android 8.0 (API level 26) or higher.
- Android device or emulator capable of running APK installations.

Alerts and Notifications:
The application allows users to configure alerts for:
- Vacation start date
- Vacation end date
- Excursion date
  Notification are delivered using Android's notification system.
